# Checklist de QA

Use este checklist antes de publicar mudancas.

## Interface

- [ ] Header renderiza sem quebrar.
- [ ] Visao geral mostra fase atual.
- [ ] Mapa mental renderiza com no central e etapas ao redor.
- [ ] Etapa atual fica destacada.
- [ ] Fases clicaveis alteram o checklist.
- [ ] Registro diario salva e aparece no historico.
- [ ] Metricas atualizam com o ultimo registro.
- [ ] Alertas aparecem conforme CPE, data e retencao.

## Mobile

- [ ] Sem scroll horizontal.
- [ ] Titulo principal quebra corretamente.
- [ ] Mapa mental empilha de forma legivel.
- [ ] Formularios continuam usaveis.
- [ ] Botoes nao ficam apertados demais.

## Dados

- [ ] Checklist fica salvo apos recarregar.
- [ ] Notas ficam salvas apos recarregar.
- [ ] Registro diario pode ser editado clicando no historico.
- [ ] Limpar `localStorage` reinicia o painel sem quebrar.
